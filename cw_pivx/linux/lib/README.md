# PIVX Sapling Native Library for Linux

This directory contains the native PIVX Sapling library for Linux.

## Building

Run the build script from the cw_pivx directory:

```bash
./scripts/build_linux.sh
```

This will:
1. Build the Rust library for Linux
2. Copy libcw_pivx_sapling.a to this directory

## Contents

After building:
- `libcw_pivx_sapling.a` - Static library for Linux
